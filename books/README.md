# Lounge bookshelf

The readable books are public-domain Project Gutenberg plain-text files.
`library.gd` lists them; drop each file in this folder under the name it
gives:

- `the_time_machine.txt` (H. G. Wells, Gutenberg #35)
- `the_secret_garden.txt` (Frances Hodgson Burnett, Gutenberg #113)

Use the "Plain Text UTF-8" download. The Gutenberg header and licence
footer are stripped automatically when a book is opened.

When exporting the game, add `*.txt` to the export filter's non-resource
files so the books are included.
